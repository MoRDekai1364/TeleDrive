| completed | critical | bug | `TeleDrive.WPF.csproj` has both `UseWPF` and `UseWindowsForms` set (needed for `TrayIconManager`'s `NotifyIcon`). Fixed by removing both implicit global usings (`<Using Remove="System.Windows.Forms" />` / `<Using Remove="System.Drawing" />`) — safe since `TrayIconManager.cs` already has its own explicit `using System.Windows.Forms;` plus an `Application` alias. |
